평소 대기에서 다음 행동 고르기

Cafe_Idle2.0 반복 로 3~8초 서 있다가 아래 확률로 다음 행동을 고릅니다. 방향은 정면 ±30° 안에서 무작위.

행동가중치나오는 동작
걷기40 돌아다니기 끄면 0Cafe_Walk1.33 반복 바닥의 아무 지점으로 최대 3칸(약 7.5초 이내) → 도착하면 대기
잠깐 무장20아래 "잠깐 무장" 참고 (15~40초 동안 총 든 동작)

그냥 계속 대기12Cafe_Idle 3~8초 더

"건드림" = 클릭 반응, 끌어 옮기기, 더블클릭 EX. 걷기·무장은 건드림으로 치지 않습니다.

잠깐 무장 (15~40초)

총을 든 대기 Formation_Idle4.4 반복 로 3~8초씩 서 있다가 매번 아래에서 고릅니다. 시간이 다 되면 맨손 대기로 돌아갑니다(총이 0.25초 만에 사라짐).

총 든 랜덤 동작60Rearrange_Idle6.4 또는 Victory_End2.0 (반반, 직전에 한 것은 피함)

왼쪽·오른쪽 중 한쪽을 적 방향으로 정하고(반반) 카메라 쪽으로 60°±20° 돌아서 싸웁니다. 전투 대기 Normal_Idle2.0 / Stand_Attack_Delay2.0 로 1.2~3.5초 쉬고 매번 아래에서 고릅니다. 탄창은 3발(사격 한 번 = 1발).
